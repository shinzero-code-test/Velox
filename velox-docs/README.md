# Velox

**App ID:** `com.exapps.velox`  
**Tagline (AR):** مشغل الوسائط القوي والسلس  
**Tagline (EN):** Powerful. Fluid. Yours.

Velox is a modern mobile media player built for speed, elegance, and deep media control. Inspired by the power of VLC, the polish of MX Player, and the music-focused clarity of Lark Player, Velox is designed **Arabic-first** with a distinctive dark glass aesthetic.

---

## Vision

Create the most refined Arabic-first media player experience on mobile — one that feels premium, never gets in the way, and gives power users complete control while remaining approachable for everyday users.

## Core Pillars

| Pillar              | Description                                                                 |
|---------------------|-----------------------------------------------------------------------------|
| **Performance**     | Instant startup, buttery scrolling, efficient decoding, low memory footprint |
| **Aesthetics**      | Dark glass surfaces, large artwork, subtle gradients, rounded cards, micro-animations |
| **Arabic-First**    | Full RTL, Arabic typography excellence, localized UX patterns from day one  |
| **Power + Simplicity** | Advanced features available without overwhelming the default experience   |
| **Privacy**         | Local-first, no forced accounts, minimal telemetry                          |
