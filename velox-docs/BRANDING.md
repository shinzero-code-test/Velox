# Velox Branding

**App ID:** `com.exapps.velox`

---

## 1. Name

**Velox**

- Latin origin meaning *swift*, *rapid*, *fleet*
- Short, memorable, easy to pronounce in Arabic and English
- Evokes speed and fluidity — core product attributes
- Available as a strong, modern brandable name

### Arabic Treatment
- **فيلوكس** (phonetic) or keep **Velox** in Latin script for logo/app name
- Preference: Keep “Velox” in Latin across languages for brand consistency, with Arabic tagline

### Taglines

| Language | Tagline                          |
|----------|----------------------------------|
| Arabic   | مشغل الوسائط القوي والسلس       |
| English  | Powerful. Fluid. Yours.          |
| Alt EN   | Media at the speed of you.       |

## 2. Brand Personality

| Trait            | Description                                      |
|------------------|--------------------------------------------------|
| **Swift**        | Instant response, no lag, efficient              |
| **Refined**      | Premium materials, careful details, restraint    |
| **Powerful**     | Deep features available when needed              |
| **Calm**         | Dark, focused, non-noisy interface               |
| **Arabic-rooted**| Designed with Arabic users as the primary lens   |

Voice: Confident, clear, modern, never childish or overly technical in consumer-facing text.

---

## 3. Logo Concept

### Direction
- Wordmark-focused with a simple symbol
- Symbol ideas:
  - Stylized “V” formed by two dynamic strokes suggesting motion / play
  - Abstract play triangle integrated into a glass-like rounded form
  - Minimal waveform + play hybrid
- Avoid: generic play buttons, overly complex emblems, cliché music notes

### Logo Versions
1. **Primary:** Symbol + “Velox” wordmark
2. **Symbol only:** For app icon adaptive layers
3. **Wordmark only:** Horizontal lockups
4. **Monochrome:** White / black versions for special use

### App Icon
- Adaptive icon (Android)
- Foreground: Velox symbol on transparent or subtle glass
- Background: Deep dark (`#0B0D10`) or soft gradient
- Safe zone respected
- Recognizable at small sizes
- Optional: subtle glow or accent highlight on the symbol

---

## 4. Color Identity

**Primary Brand Color:** Velox Teal — `#2EE6A6`

Supporting:
- Deep background: `#0B0D10`
- Glass whites at low opacity
- Clean neutral grays for text

The teal should feel energetic but not aggressive — modern, fresh, and distinct from the reds/oranges common in many media players.

---

## 5. Typography (Brand)

- **Latin brand font:** Plus Jakarta Sans or similar geometric sans
- **Arabic brand font:** IBM Plex Sans Arabic or Cairo
- Consistent weight pairing across scripts
- App name in logo may use a slightly customized or tightly tracked treatment

---

## 6. Visual Language Summary

- Dark glass surfaces
- Large, high-quality artwork
- Soft gradients and light borders
- Generous rounding
- Purposeful micro-animations
- High contrast text on dark
- Accent used sparingly for actions and progress

This language should extend to:
- Play Store screenshots
- Feature graphic
- Website (future)
- Social templates
- In-app empty states and onboarding

---

## 7. Voice & Tone Guidelines

### Do
- Be direct and helpful
- Use clear, modern Arabic (not overly formal classical, not overly slangy)
- Celebrate media and the listening/watching experience
- Speak with quiet confidence

### Don’t
- Use excessive exclamation marks
- Over-promise (“best player in the world”)
- Use childish language or memes in core UI
- Mix too many English terms in Arabic UI without need

### Example UI Strings (Arabic)

| Context              | String                          |
|----------------------|---------------------------------|
| Empty library        | لا توجد ملفات بعد. أضف مجلدات للبدء |
| Now Playing          | قيد التشغيل                     |

| Equalizer            | معادل الصوت                     |
| Sleep timer          | مؤقت النوم                      |
| Scan library         | فحص المكتبة                     |
